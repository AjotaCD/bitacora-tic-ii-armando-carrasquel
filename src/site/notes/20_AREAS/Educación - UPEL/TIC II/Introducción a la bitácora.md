## Mi elección de herramienta. Digital Garden

Originalmente, este registro se planteó como un blog convencional en Blogger. Sin embargo, en la búsqueda de un sistema que realmente potencie el aprendizaje interconectado y la gestión del conocimiento, he decidido migrar hacia un **Digital Garden**. Esta es una herramienta que funciona como un "publisher" para publicar notas de obsidian a modo de pagina web ([Obsidian](https://help.obsidian.md) es un software de toma de notas en formato estandarizado markdown que permite mantener una jerarquia de encabezados simple).
El mayor desafio que pude encontrar durante la integración de esta herramienta fue la configuración del servidor con la herramienta Vercel y Github como host del repositorio. Sin embargo me parece la mejor manera de establecer mi bitácora

Esta evolución me permite:
- **Superar la linealidad:** En lugar de simples entradas cronológicas, construyo una red de notas vinculadas que crecen y se refinan con el tiempo.
    
- **Integración Nativa con Obsidian:** Publico directamente desde mi entorno de trabajo, lo que garantiza que el contenido sea un reflejo fiel de mi "cerebro digital".
    
- **Capacidad Multimodal:** Facilita la futura integración de herramientas como **Obsidian Canvas** para el Tablero Digital, elevando el estándar técnico de la entrega.

# Guia estructural

### Justificación: Adaptación y Sostenibilidad Física

Como estudiante con **hiperlaxitud articular**, la eficiencia en la interacción con el software es fundamental para evitar la fatiga física. El flujo de trabajo del Digital Garden optimiza mi rendimiento al:

- **Reducir clics y fricción:** Escribo en Markdown localmente y publico con un solo comando.
    
- **Organización Orgánica:** Permite una reflexión crítica profunda sin las distracciones de interfaces web pesadas.
    
- **Cumplimiento de Criterios:** Esta transición es, en sí misma, una evidencia de **Uso de la Herramienta (4%)** y **Creatividad (4%)**, al proponer una solución tecnológica superior para cumplir con los objetivos académicos.
    

### Arquitectura del Jardín

He diseñado este espacio bajo un modelo de **Nodo Central**, asegurando que el profesor Mg. Edgardo Yrausquin mantenga la claridad en la navegación:

1. **Portada e Índice Innegociables:** El punto de entrada siempre será la identificación formal y el acceso estructurado a las actividades.
    
2. **Registro Cronológico:** Aunque el jardín es no lineal, he implementado una sección de **"Entradas Recientes"** para respetar la organización temporal exigida en la planificación.
    
3. **Transparencia Técnica:** Dado que las plataformas de publicación pueden omitir funciones estéticas de Obsidian (como los _callouts_), incluyo capturas de pantalla de mi entorno local como evidencia de mi proceso de organización avanzado.
